# EDA Findings – Student Performance Analysis

## Key Findings

1. The dataset contains 100 student records and 10 columns.

2. The dataset contains no missing values after data checking.

3. No duplicate records were found in the dataset.

4. The analysis compares student performance across Mathematics, Science and English.

The exploratory data analysis provides a basic understanding of student academic performance. The findings can help identify important factors related to student results and can support further analysis using Power BI.
