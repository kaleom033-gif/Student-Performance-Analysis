# Student Performance Analysis

## Project Overview

Student Performance Analysis is a data analytics project that analyzes student academic performance using Python, Excel and Power BI.

## Objective

The main objective of this project is to analyze student performance based on study hours, attendance, gender, city and subject-wise marks.

## Dataset

The dataset contains student information and academic performance details.

### Dataset Columns

- Student_ID
- Student_Name
- Gender
- City
- Study_Hours
- Attendance
- Math_Score
- Science_Score
- English_Score
- Result

## Tools and Technologies

- Python
- Pandas
- Matplotlib
- Excel
- Power BI
- Git and GitHub

## Expected Outcome

The project will identify important patterns in student performance and provide useful insights for improving academic results.
